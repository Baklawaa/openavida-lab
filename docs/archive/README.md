# Archive — phase-1/2 build transcripts

The three `grok-gauntlet*.md` files in this directory are the prompt-driven
build transcripts from the phase-1 and phase-2 construction of the project:
each one is an autonomous-agent brief (the "gauntlet loop" instructions, the
project facts and the task list) followed by the running account of
implementing it. `grok-gauntlet.md` covers the first loop, `grok-gauntlet-2.md`
the second, and `grok-gauntlet-multicellular.md` the multicellularity loop.

They are kept for provenance — they record how the phase-1/2 design was
arrived at, which decisions were made without asking, and what the code looked
like at the time. They are not user documentation and are not maintained: the
file paths, flags, gate commands and behaviour they describe have moved on, and
some of the tasks in them were later superseded or marked BLOCKED. Read them as
history, not as instructions.

The documentation that is maintained lives one directory up, indexed in
[../README.md](../README.md).
